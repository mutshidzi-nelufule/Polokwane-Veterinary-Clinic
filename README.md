# Polokwane Veterinary Clinic Management System

## Project Overview
The Polokwane Veterinary Clinic Management System is an Android application designed to assist with managing veterinary clinic activities.

## Main Features
- User login and registration interface
- Dashboard for navigating clinic functions
- Pet owner management
- Animal management
- Appointment management
- Treatment records
- Billing and invoice management
- Reports and settings

## Technologies Used
- Kotlin
- Android Studio
- Jetpack Compose
- Gradle
- SQL database scripts

## Project Structure
- `app/` – Android application source code
- `database/` – Database schema and sample data scripts
- `gradle/` – Gradle wrapper and build configuration
- `README.md` – Project documentation

## Running the Project
1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Connect an Android device or start an emulator.
5. Run the application.
